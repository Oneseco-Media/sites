## Telegram Fileshare Module

The app now includes a Telegram Fileshare flow in `/tmp/workspace/Oneseco-Media/sites/js/modules/telegramFileshare.js`.

### How to use

1. Run the app (`npm start`) and open the page.
2. Enter a public `http` or `https` file URL.
3. Optionally enter a file name and caption.
4. Select **Share via Telegram** to open Telegram's share URL flow.
